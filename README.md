# SocialMERN — Social Media Web Application

A social media web application project built with **React, JavaScript, and Vite**, focused on modern frontend development and reusable UI components.

## Overview

SocialMERN is a web development project for exploring social networking interfaces and full-stack application concepts.

## Tech Stack

- **Frontend:** React, JavaScript, Vite
- **Styling:** Tailwind CSS
- **State Management:** Redux Toolkit, React Redux
- **Routing:** React Router
- **API Requests:** Axios
- **UI Components:** Radix UI
- **Icons:** Lucide React, React Icons
- **Real-Time Client:** Socket.IO Client

## Features and Technical Highlights

- Component-based React architecture
- Reusable UI components
- Client-side routing
- State management with Redux Toolkit
- API integration support using Axios
- Responsive styling with Tailwind CSS
- Dependencies available for real-time communication

## Getting Started

### Prerequisites

- Node.js (LTS recommended)
- npm

### Installation

Clone the repository and navigate to the frontend directory:

```bash
git clone https://github.com/SuchitaChanghate/Social-Mern.git
cd Social-Mern/SocialMERN-master
npm install
npm run dev
```

Open the local URL displayed in your terminal.

## Available Commands

| Command | Purpose |
|---|---|
| `npm run dev` | Start the development server |
| `npm run build` | Build the application |
| `npm run preview` | Preview the production build |
| `npm run lint` | Run ESLint checks |
